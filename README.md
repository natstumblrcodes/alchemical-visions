# Alchemical Visions

Custom mobile-first psychic consultation portal built from the supplied visual references.

This repository is intentionally separate from the older curly-octo-goggles project.

Current milestone: responsive front-end shell with welcome, sign-in/create-account, text chat, audio/video call states, away/offline/queue states, payment UI, navigation, and the gold/purple celestial visual system.

Next: connect Supabase Auth/Realtime, owner presence, messaging, WebRTC signaling, wallet/session billing, Stripe, and appointments.
